Core invariants

  1. A Semantic IR dump contains no physical target/storage decisions.
  2. A Lowered IR tensor retains semantic origin but contains no device addresses or executable handles.
  3. A Physical Plan is immutable after finalization; all references are validated before runtime use.
  4. Required artifact versions/capabilities fail closed; unknown optional sections may be skipped.
  5. Identical normalized inputs and tool version produce identical dumps and artifact bytes.
